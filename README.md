# Chess Engine

A chess engine written from scratch in Python. The project focuses on implementing classic chess engine techniques while experimenting with modern machine learning approaches for position evaluation.

> **Project Status:** 🚧 Active Development

## Current Features

* Alpha-beta search
* Quiescence search
* Transposition table
* Move ordering optimizations
* Engine testing and benchmarking tools

## Neural Network Evaluation (Work in Progress)

I am currently developing an **NNUE-inspired evaluation function** to replace or complement the handcrafted evaluation.

Current work includes:

* HalfKP feature encoding
* Training data generation
* TensorFlow/Keras training pipeline
* Model architecture experimentation
* Performance and accuracy optimization

This part of the project is still under active development and is not yet integrated into the main engine.

## Technologies

* Python
* TensorFlow / Keras
* python-chess
* NumPy
* Pandas
